# Frontend design vocabulary

Use language to open possibilities and make feedback actionable. These verbs are optional creative lenses, not a sequence, scoring system, or set of aesthetic rules. Natural-language requests are sufficient; no special command syntax is required.

## Apply in context

Read the relevant interface and the user's intended experience. Interpret the requested quality in that context and act within the existing scope. When ambiguity materially changes the direction, make alternatives visible or ask a focused question; otherwise proceed with a reasonable interpretation. Preserve the work's distinctive character during refinement, and explore a new direction when redesign is requested.

Use one or a few useful lenses, not the entire vocabulary. Translate the interpretation into observable changes and inspect the result in the relevant medium. Explain the difference briefly when it helps the user judge it. Critique requests produce observations and recommendations; they do not automatically authorize edits.

## Vocabulary

| Lens | Useful design question |
| --- | --- |
| Shape | What experience, structure, or interaction would make the intention tangible? |
| Critique | What is compelling, what feels unresolved, and what evidence explains that judgment? |
| Bolder | Where could a clearer point of view make this more distinctive? Scale, composition, imagery, language, or interaction may matter more than saturation. |
| Quieter | Which competing signals can recede while the character remains? |
| Distill | What can be removed or combined so the essential idea becomes stronger? |
| Typeset | How can lettering, hierarchy, measure, and rhythm strengthen the voice and reading experience? |
| Layout | How can proximity, space, alignment, or deliberate interruption clarify relationships? |
| Colorize | What role could color play in atmosphere, meaning, hierarchy, or response? |
| Animate | What change, relationship, or character could timing and movement express? |
| Delight | What specific, fitting detail would reward attention or make an action memorable? |
| Overdrive | What ambitious technique could make this particular experience extraordinary? Responsiveness or elegant behavior can be as compelling as spectacle. |
| Clarify | How can wording, hierarchy, or feedback make intent and consequences easier to understand? |
| Adapt | How should the experience change for a different device, context, or access need? |
| Harden | What happens with awkward content, interruptions, errors, or unusual states? |
| Optimize | Where can the experience become faster or smoother without losing its defining qualities? |
| Polish | Which remaining inconsistencies weaken the chosen direction? |
| Audit | Which relevant properties can we actually check, and what remains unverified? |

These are starting points. Combine, reinterpret, or extend them when the work calls for it. Their names are not evidence that a change succeeded.

## Creative freedom

The user's intention and project context determine taste. Fonts, colors, geometry, illustration, effects, and techniques are available choices; this skill imposes no house style or universal aesthetic bans. Propose surprising alternatives when useful. Preserve applicable usability and accessibility needs while exploring expressive form.

Do not create or activate a design profile unless the user names its file or key. This skill adds no setup documents, hooks, runtime, automatic detector, mandatory review count, or fixed production stack. It complements the studio workflow rather than replacing it. Expand it only when actual use reveals a useful missing distinction.
