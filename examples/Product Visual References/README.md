# Product screenshot presentation references

These 22 user-supplied images inform product presentation composition: focus, useful context, crop, scale, reading order, and depth. The user describes the set as Claude-inspired. Visible names and marks support that description, but original authors, source URLs, capture dates, authenticity, and reuse rights are unverified. The images are visual evidence, not confirmation that any depicted feature, model, integration, or release exists today.

All 22 originals were opened and visually inspected on October 10, 2026. Dimensions were read from the files; all are 16:9. Larger images were displayed at up to 2048 × 1152 for composition inspection, not audited word by word at native resolution. Original filenames and bytes are preserved. Observations below describe visible arrangements; they do not establish how those arrangements were produced.

Use the [provisional Databricks presentation profile](<../../Design systems/Databricks-Design/product-visual-references.md>) to adapt these references and the [lightweight review](<../../Design systems/Databricks-Design/product-visual-references-eval.md>) to compare candidates. Open only the 1–3 examples relevant to a brief. Candidate uses are descriptive observations, not required categories or user-approved preferences.

## Interpretation boundaries

Common observations are large UI crops, quiet outer fields, selective context, and soft separation between layers. Exceptions matter: S21 preserves broad context, S03–S04 contain marks rather than screens, and S01/S05 communicate breadth through deliberate density. Orange, pale green, serif headlines, starburst marks, pixel characters, and large illustrated pointers are visible reference styling, not universal requirements or Databricks tokens.

No reference has been selected as the user's preferred direction, and no Databricks candidate has been evaluated. Add future selections and rejections to the relevant project's review notes; keep this source index descriptive.
